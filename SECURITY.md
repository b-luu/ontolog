# Security policy

Security fixes target the latest Ontolog alpha release and the main branch.
Older alpha versions do not receive separate security updates; upgrade to the
latest release when a fix is published.

Report suspected vulnerabilities using [GitHub private vulnerability reporting](https://github.com/b-luu/ontolog/security/advisories/new).
Include reproduction steps and the affected version using synthetic data.
Do not include vulnerabilities, company records, credentials or other sensitive
details in public issues or pull requests. Response times depend on maintainer
availability; there is no guaranteed response deadline.

See [repository maintenance](docs/maintenance.md) for security checks and their limits.
