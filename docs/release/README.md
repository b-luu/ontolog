## Claim boundaries

The author supplied the broad client-work experience and prior data-domain knowledge-base work. Keep specific clients, figures, testimonials, and pilot outcomes out unless separately supported and authorized. Ontolog has an interview procedure, structural checks, ejection, local skill installation, and ZIP export. It has not demonstrated real-world interview efficacy or implemented autonomous synchronization, formal ontology reasoning, an API, or MCP server.

The template's company `records/` is empty. The public bundle also contains isolated fictional examples, omitted by default on ejection. The open-source license covers the reusable kit, not permission to publish company contributions. General analytical methods remain outside this release; company-specific interpretation caveats can be captured or linked.
